# Projeto Previsão do tempo ⛅
### O projeto previsão do tempo tem como funcionalidades:
* Receber uma cidade para a verificação
* Listar a temperatura
* Listar a temperatura mínima e máxima
### API utilizada para desenvolver o projeto: https://openweathermap.org/current
### Ferramentas utilizadas:
* HTML5 | CSS3
* JavaScript | React
* Git | GitHub
* Integração com API
